# Лабораторна робота №5. Ruby. Базове ознайомлення. Частина 2

Мікрозадачі на Ruby: масиви, ітератори (`each`, `select`, `find`, `map`, `any?`), цикли, класи (`Money`, `Worker`).
Кожна програма першим рядком виводить привітання «Привіт, Владислав Мельник!».

| Файл | Завдання |
|---|---|
| `task1.rb` | привітання `"Привіт, #{name}!"` |
| `task2.rb` | кількість входжень максимальної цифри у введене число |
| `task3.rb` | сума парних членів послідовності Фібоначчі, що не перевищують 4 000 000 |
| `task4.rb` | результати 20 футбольних ігор (виграш / програш / нічия) |
| `task5.rb` | найменше 4-значне число, яке зменшується на 27 після перестановки останньої цифри на початок (`find`) |
| `task6.rb` | чи є 15485863 простим числом (`each` і `any?`) |
| `task7.rb` | квадрати чисел <= 1000, що закінчуються на 396 (`map`) |
| `money.rb`, `task8.rb` | клас `Money` (гривні + копійки): `+`, `-`, `*`, `/` на дробове число, порівняння; перевірка у функції `main` |
| `worker.rb`, `task9.rb` | клас `Worker` з методами `setName`/`getName`, `setAge`/`getAge`, `setSalary`/`getSalary`; сума зарплат і віку Івана та Васі |
| `task10.rb` | доповнення класу `Worker` методом `checkAge` (вік 1–100), який використовує `setAge` |

## Запуск

Потрібен Ruby 3.x (перевірено на Ruby 3.4.9 в Ubuntu 24.04, встановлений через RVM).

```
ruby task1.rb
ruby task2.rb      # далі ввести число, напр. 77777
ruby task3.rb
...
ruby task7.rb
ruby task8.rb
ruby task9.rb
ruby task10.rb
```
